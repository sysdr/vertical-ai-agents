# L74 MLOps Pipeline

Standalone backend + frontend project for deployment-state monitoring demos.

## First-time setup

- Create local env file:
  - `cp .env.example .env`
- Add your key in `.env`:
  - `GEMINI_API_KEY=...`

## Quick Commands

- Start app:
  - `./start.sh`
- Stop app:
  - `./stop.sh`
- Run tests:
  - `./test.sh`
- Build:
  - `./build.sh`
- Cleanup Docker/resources:
  - `./cleanup.sh`
